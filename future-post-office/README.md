# 未来邮局

线上地址：https://roubizhao6-sys.github.io/future-post-office/

面向中国大陆年轻人的低价数字时间胶囊产品。

用户把文字、照片和未来开启日期交给卖家，卖家生成一个单文件HTML时间胶囊。收件人在指定日期后输入密码，才能打开内容。

## 产品定位

不是让AI替代用户写信，而是把真实内容、照片和日期封装成有仪式感的数字礼物。
